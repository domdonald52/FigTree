Email on the domain

When the nameservers moved to Netlify, the domain’s old MyHost mail (MX) record didn’t come across, and the domain currently has no MX record. If anyone used an @catepates.co.nz address, add MyHost’s MX and SPF records in Netlify DNS before setting up hello@catepates.co.nz.

How changes reach the live site

Work goes to the preview branch for free; the live site only changes when that work is merged into main, which costs 15 Netlify credits.

  1. Claude (or you) commits to claude/cate-pates-portfolio-l2zfyj and pushes to GitHub.
  2. Netlify builds a branch deploy at claude-cate-pates-portfolio-l2zfyj--figtreestudionz.netlify.app. Branch deploys cost no credits.
  3. When you’re happy, open a pull request from that branch into main on GitHub and merge it. Netlify builds production at catepates.co.nz: one deploy, 15 credits (the free plan has 300 a month).
  4. Group several changes into one merge to save credits.

Saving credits

  • netlify.toml has an ignore rule: a push that changes nothing under site/, scripts/, netlify/ or the package files (for example a README edit) doesn’t build at all.
  • Content edits in the Google Sheet and Stripe sales never need a deploy: the site reads them live.
  • Never press Trigger deploy at the top of the Deploys page unless you mean to rebuild production. To rebuild the preview, open its latest branch deploy and choose Retry deploy.
  • Settings changes (environment variables) only take effect after the next build of that branch.

Working with Claude

  • Claude Code sessions run in the cloud from Dom’s Claude account and push to GitHub through the Claude GitHub app. They work on the claude/… branch, never on main directly.
  • Run one session per branch at a time. Two sessions pushing to the same branch collide.
  • The project README.md holds the same setup notes plus a To do with Cate checklist, so a new session can pick up where the last one left off.

How each part works

Content from the Google Sheet

The function /api/sheet?tab=<Tab> fetches one tab of the website sheet (Workshops, Studio, Galleries, Exhibitions or Media) through Google’s public query endpoint and returns it as JSON. Netlify’s CDN caches each answer for 5 minutes, so edits appear within about 5 minutes. The pages read these tabs in the browser; if the sheet can’t be reached they fall back to the files in site/data/ and the text in the HTML. Only those five tabs can be read; the Sales sheet is a separate private file and never goes near the website.

Selling a studio piece

  1. Each Studio row has a Stripe payment link. The page adds client_reference_id=<code> (the row’s Code, lower-cased, e.g. fox-01) to the Buy button’s link.
  2. The buyer pays on Stripe’s checkout page and is sent to /order-thanks.html.
  3. Stripe calls /api/stripe-webhook. The function checks Stripe’s signature with STRIPE_WEBHOOK_SECRET and, once the payment has gone through, saves the code in a Netlify Blobs store called studio-sold.
  4. The Gallery page asks /api/studio-sold and shows that piece as Sold. Cate also types yes in the Sold column as her own record.

The payment link is limited to one payment, so a piece can’t sell twice even if the site is slow to update.

ORA and The Vault

At each build, scripts/fetch-ora.mjs reads ORA’s Shopify feed and scripts/fetch-vault.mjs reads Cate’s artist page on thevaultnz.com. Both crop the photos to a matching 4:5 frame and save them with site/data/ora.json and site/data/vault.json. In the browser, ORA is also checked live: sold pieces vanish and new ones appear at once. The Vault has no feed, so its list is only as fresh as the last build. If either source is down or changes its layout, the last good list is kept.

Contact form

A Netlify Form called contact on the About page. Messages are kept under the project’s Forms and emailed to the address in the form notification settings. A hidden honeypot field filters spam.

Checking and fixing

Start with the status page, /status.html on the preview or the live site. It shows a tick or cross for each sheet tab (with row counts and how many studio pieces have a payment link), whether the Stripe signing secret is set, and which pieces Stripe has marked sold. It never shows secrets or buyers’ details.
